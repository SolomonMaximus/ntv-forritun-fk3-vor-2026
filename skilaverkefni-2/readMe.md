# Team Task Hub - Skilaverkefni 2

This project is based on the Team Task Hub app from `skilaverkefni-1`.

The goal of `skilaverkefni-2` is to add useful testing tools to the existing app. The app itself is still the same Team Task Hub idea, but this version adds Vitest tests, Storybook stories, Cypress E2E tests, a CI workflow, and fixes for bugs found while testing.

## Original base project

This assignment builds on the provided `skilaverkefni-1` solution:

https://github.com/CCP-2FaceMonkey/ntv-forritun-fk3-vor-2026/tree/main/solutions/skilaverkefni-1

## What was added

For this assignment I added:

- Vitest for unit tests
- React Testing Library / Testing Library tools
- Storybook for viewing UI components in isolation
- Cypress for end-to-end browser testing
- GitHub Actions CI workflow
- Tests for reducer logic and task search behavior
- Cypress test for a realistic project/task user flow
- Fixes for two bugs found while testing

## Install dependencies

Run this inside the `skilaverkefni-2` folder:

npm install
